# SunFixer & OVM Official Website

Official website for Ukrainian electronic music duo **SunFixer & OVM** and their record label **CORE64 Records**.

## About

SunFixer & OVM are Ukrainian electronic music producers and creators based in Irpin, Kiev Oblast. They specialize in dark, intricate electronic music spanning multiple genres:

- **Dark Drum & Bass** - Heavy, aggressive style with dark atmospheres
- **Neurofunk** - Dark subgenre with complex basslines and futuristic sound design  
- **Breakbeat** - Electronic music utilizing chopped drum breaks
- **JumpUP** - High-energy drum and bass with bouncing basslines
- **Jungle** - Fast breakbeats with reggae and dancehall influences
- **Dub** - Reggae-derived genre with heavy echo and electronic manipulation
- **Dubstep** - Electronic dance music with syncopated drums and prominent basslines

## CORE64 Records

Their label **CORE64 Records** draws inspiration from the legendary era of analog synthesizers and 8-bit Commodore C64 computers, representing the evolution from vintage to modern Core 64 CPUs used in electronic music production.

### Label Philosophy
- Blending elements of new wave and EDM disco
- Deep and darker instrumental songs
- Always incorporating 808 sounds with 1980s inspiration
- Founded on the legacy of early digital music production

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/AnatoliiNovyk/sunfixer-ovm-website.git
```

2. Navigate to the project directory:
```bash
cd sunfixer-ovm-website
```

3. Open `index.html` in your web browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server installed)
npx http-server
```

4. Visit `http://localhost:8000` in your browser
